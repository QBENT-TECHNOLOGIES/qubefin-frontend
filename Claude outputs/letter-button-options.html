Letter actions — merged

Four ways to collapse View & Print / Send / Received into one control. Same three handlers behind each.

Option 1

Segmented pill with a name plate

The letter name is stated once, on the left, so the three actions shrink to verbs. One object per letter instead of three loose pills — the Actions card reads as a list of letters, not a wall of buttons.

Option 2

Split button — one obvious next step

Send is the action you actually want 90% of the time, so it gets the weight. View & Print and Mark Received move into the caret menu. Smallest footprint, but it hides two actions behind a click.

↖ click to open
Option 3

Letter row — name left, actions right

A full-width row per letter. Costs vertical space, but it scales best if two letters are ever open at once, and leaves room for a due date or a "sent 3 days ago" line under the name later.

Welcome Letter
Option 4

Icon rail — most compact

Name as plain text, three icon buttons with tooltips. Tightest of the four, and the riskiest: "print" and "mark received" are not obvious from an icon alone to someone using this once a month.

My pick: Option 1. It's the only one that keeps all three actions visible while still reading as a single object, and it drops from ~62 characters of button text to ~34 by saying the letter's name once. It also survives the disabled/“Sending…” states you already have, which Option 2 would have to reproduce inside a menu. Option 3 is the better choice only if you later want per-letter metadata under the name.

Same three click handlers in every option — only the markup around them changes.
